Sample Formula Explanation

Using Slovin's Formula with N = 232 and e = 0.05:

n = N / (1 + N * e²)
n = 232 / (1 + 232 * 0.0025)
n = 232 / 1.58 = 146.835 ≈ 147

Stratified proportions are calculated using nᵢ = (Nᵢ / N) × n to ensure each stratum is accurately represented.
